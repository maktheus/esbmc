# Fonte do modelo público no Overleaf

`main.tex` contém o fonte principal exibido publicamente na página [Modelo de Relatório de PIBIC UFAM](https://pt.overleaf.com/latex/templates/modelo-de-relatorio-de-pibic-ufam/xgntxbfshpgb), de Danilo Chui, disponibilizado sob licença CC BY 4.0.

## Limitações

- O projeto público é de aproximadamente 2021 e foi preparado para PIBIC/PAIC, com configuração de relatório parcial/final.
- O fonte principal referencia arquivos `.tex`, imagens e estilos que a página pública não expõe individualmente sem abrir/copiar o projeto no Overleaf. Portanto, esta pasta **não é um pacote LaTeX autônomo completo**.
- O PDF correspondente está em `../Overleaf_modelo_relatorio_PIBIC_UFAM.pdf` e serve como referência visual.
- Para o Relatório Final PIBIC 2025/2026, o guia administrativo vigente `../UFAM_guia_relatorio_PIBIC_exatas.pdf` deve prevalecer em estrutura e seções obrigatórias (correção de identificação de 30/08/2026: o programa é PIBIC/PROPESP, não PIBITI/PROTEC).

O `main.tex` pode ser usado para recuperar escolhas tipográficas e organização, mas não deve substituir os requisitos atuais da PROTEC.
