## Antes de enviar
1. **QR Code (obrigatório):** suba o resumo expandido no Drive ("Qualquer pessoa com o link", Leitor), gere o QR no Canva,
   salve como `qr.png` nesta pasta e rode `node render.js`. Teste com a câmera do celular.
2. O modelo recebido (`Modelo_Banner - CONIC 35.pptx`) é o **antigo** (3401×4535 px, Bahnschrift). Esta versão adapta a
   estrutura para 1080×1920 (9:16) e Arial, conforme o FAQ. Se sair o modelo novo, migrar o conteúdo para ele.
3. Seção **Agradecimentos** do modelo não coube em 9:16 com fonte legível; e-mails dos autores não foram incluídos.
